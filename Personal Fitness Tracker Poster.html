01Abstract

Most people exercise without a simple record of what they did or whether they are improving. The Personal Fitness Tracker is a menu-driven Java program where a user registers a profile, logs workouts (running, cycling, strength), records daily steps and sets goals.

The system calculates calories burned and BMI, summarises weekly totals, ranks best sessions and saves everything to files so data survives between runs. Invalid input is caught and handled, so the program never crashes on bad data.

static int total(int[] a, int i) {
  if (i == a.length) return 0;
  return a[i] + total(a, i + 1);
}
CO4

Objects that Fail Safely

  • Classes User, Workout with private fields & getters/setters
  • Abstract Workout; subclasses override calories() (polymorphism)
  • Custom InvalidInputException + try-catch keeps the app running
abstract class Workout {
  abstract double calories();
  void setMinutes(int m) throws InvalidInputException {
    if (m <= 0) throw new InvalidInputException("Minutes must be > 0");
    this.minutes = m;
  }
}

list.sort(Comparator.comparingDouble(Workout::calories).reversed());
try (BufferedWriter bw = Files.newBufferedWriter(path)) {
  for (Workout w : list)
    bw.write(String.join(",", w.type(), w.date(), "" + w.calories()) + "\n");

The Personal Fitness Tracker turns a real everyday problem into a working Java program. It brings together every course outcome — structured problem solving, control flow, modular methods with recursion and arrays, safe object-oriented design with exceptions, and string handling, library algorithms and file storage.

The result is a reliable, easy-to-use tool with a persistent fitness history and clear progress feedback — a solid base for future GUI, database and wearable features.
